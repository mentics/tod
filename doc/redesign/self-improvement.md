# Self-improvement

## REQ-IMPROVE-01 · Capture feedback where the work happens

**Improve this** opens a short lesson editor from a result, agent reply, request, run, or selection. It keeps the source and the user's words. Lessons can be found and grouped with the same query and results components as other items.

**Acceptance** — Capture a lesson from a conversation without leaving it. Open the saved lesson and follow its evidence back to the original turn.

## REQ-ANALYZE-01 · Analyze a selection or a saved view

Users can ask for a summary, statistics, or patterns across matching tasks, sessions, transcripts, or lessons. Analysis records its input membership, time window, and definitions. The user can schedule the same analysis against fresh matches from a live view and drill from results back to supporting records.

**Acceptance** — Analyze a group of agent sessions, open examples behind a finding, and repeat the analysis with a later window while retaining the original scope and report.

## REQ-MEASURE-01 · Track changes and watch metrics

Users can create an improvement task from a finding, link it to the change they made, and record when that version took effect. They can define a metric, baseline, and alert threshold for a saved view. The result shows the size and time window of each comparison group, alongside concurrent changes that might affect interpretation. Metric alerts enter the attention queue and link to the affected data.

Start with measures such as throughput and its rate of change, cycle time, rework, human interruptions, and agent cost. Analyze improvement work itself using the same tools. For example, track how long it takes to turn lessons into deployed changes, and how often those changes have a measurable effect.

**Acceptance** — Link a proposed agent rule change to a metric, compare before and after deployment, and open a threshold alert to inspect the tasks or sessions behind it.
